-- Class Organizer --

**Project Description**: This was a rather simple project I made in python to help with my procrastination. At its core, it generates a schedule over a 
block of time and allocates tasks from assignments evenly across days. Days can be blocked for no work if desired. I plan on adding more functionality in the future, 
as well as adding a UI for easier scheduling.
